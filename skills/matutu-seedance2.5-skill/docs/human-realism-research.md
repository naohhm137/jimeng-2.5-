# Human Realism 研究资料与采用原则

本文记录 Seedance 2.5 Skill V2.0 Human Realism Engine 背后的研究资料与采用原则，说明哪些“真实感”判断被转成了可执行动态。公开语料抓取记录见 `docs/corpus-adoptions.md`，本文不包含外部原文复制。

## 研究范围

V2 的 Human Realism 不是图像画质堆叠，而是以下可执行系统的组合：

- 身份系统：人物跨镜不变的稳定外观锚点。
- 视觉行为系统：注视、眨眼、扫视、转头中的眼-头时间差。
- 表情系统：表情过程、肌肉幅度、非对称、自然恢复。
- 生物力学系统：重心、重量转移、启动与停止、骨盆与肩部代偿。
- 材质物理系统：头发、布料、皮肤、反光对重力与受力的响应。
- 光学与摄影机系统：对焦、曝光、抖动、运动模糊与真实成像行为的绑定。
- 时间系统：镜头内状态、跨镜头状态与序列状态的连续传递。

## 采用原则

1. 动态优先于形容词：`photorealistic / 8K / masterpiece` 不回答“动作如何发生”，因此不能替代 Human Realism。
2. 因果链优先于结果词：只写“走路自然”“微笑自然”不可执行；写成身体动作 -> 材质响应 -> 延迟 -> 重力归位。
3. 最小充分模块：景别与动作决定加载模块，静态胸像不加载 gait，远景不加载毛孔，避免模块过载与互相冲突。
4. 可量化窗口：眨眼、表情峰值、延迟帧、幅度区间写成可检查的时间窗口，而不是“稍微”“微微”这类含糊描述。
5. 时间连续性优先于重复咒语：跨镜一致性通过复用同一条 Identity Block 与状态机实现，不通过反复堆叠“保持一致”。
6. 身份与真实感分层：Identity 回答“是谁”，Realism 回答“如何活着”；两者合并会互相污染，导致越锁越僵。
7. 诚实覆盖度：Reference 没有提供的信息标记为 MISSING 或 LOW，不靠漂亮文字假装锁定。
8. 风险先于投喂：没有真实视频前只输出 `PRE-GENERATION RISK SCORE`，不把 Prompt 就绪度当作生成质量。

## 典型证据到执行的转换

| 证据类型 | 采用原则 | 落点模块 |
|---|---|---|
| 眼球运动不是连续平滑扫描 | 转头前视线先跳视，注视有对象与起止时间 | `eye-dynamics.md` |
| 眨眼不是固定节拍器 | 由注意、情绪、对话与摄影机共同决定，多人不同步 | `eye-dynamics.md` |
| 表情需要过程 | neutral -> response -> peak -> relaxation | `face-dynamics.md` |
| 真脸存在轻微不对称 | 左右脸肌肉保留 10-30% 幅度差 | `micro-expression.md` |
| 走路是重心转移 | 脚、骨盆、肩、臂按因果链描述 | `body-biomechanics.md` |
| 布料有质量与刚度 | 折痕生成、滞后、回弹，不同面料差异处理 | `clothing-dynamics.md` |
| 头发不是单一刚体 | 发丝分层、不同长度不同延迟 | `hair-dynamics.md` |
| 皮肤随光与表情变化 | 高光分区、肤色自然色差、皱纹随肌肉形变 | `skin-dynamics.md` |
| 摄影机也有物理 | 对焦呼吸、曝光修正、运动模糊只在运动时出现 | `camera-realism.md` |
