# Hair Dynamics

假发感的来源是“整颗头同步运动、无重力、无延迟、无发丝级差异”。

核心规则：

> Hair does not move as a single solid object.

## 动态要素

```text
individual strands
flyaway hair
baby hair
hair inertia
gravity
momentum
collision
delayed response
different strand trajectories
```

## 转头与走路

人物转头时按因果链写：

```text
head movement
-> hair follows
-> slight delay
-> different strands react differently
-> gravity restores final position
```

具体写法示例：

```text
人物向左转头，发丝随头部先到约70%行程，
较长的发尾与额前碎发滞后约2-3帧，
外侧发束因惯性轻微外甩后回落，
不同长度的发丝速度不一致，最后停在中性下垂位。
```

## 规则

- 静态镜头中头发仍然有极轻的呼吸/空气扰动，不是塑料雕塑。
- 风必须来自同一方向，额发、鬓发、后发与衣服向同一方向响应。
- 低头时发丝沿重力前垂；抬头后额发先滑落，后部发束延迟归位。
- 头发与肩膀、衣领接触时有真实遮挡关系，不穿模。

## 禁止

```text
synchronized hair movement
rubber hair
floating hair
rigid hair
hair teleportation
发丝无差别同速运动
```
