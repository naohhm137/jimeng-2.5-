# Environmental Realism

人物不是抠像贴在环境里。环境必须与人物的头发、衣服、皮肤高光、影子和物理状态发生可验证的关系。

## 动态要素

```text
background people
reflections
shadows
wind
dust
fabric
glass
water
light response
ambient movement
```

## 环境作用链

```text
wind
-> hair
-> clothing
-> nearby foliage
```

禁止让头发在无风环境孤立移动。写风时必须同时给出方向与受影响对象：

```text
镜头外左侧持续来风，
亚麻外套下摆与袖口向镜头右侧摆动，
额前碎发向同一方向扬起，身后植物同步晃动，
人物逆风行走时衣服先于身体到达下一帧位置。
```

## 规则

- 人物脚下要有正确影子，多人同框时影子方向一致。
- 镜面、玻璃、桌面反光应与人物/产品运动一致，反光位置随机位变化，不是固定贴图。
- 环境光源变化会改变人物肤色高光；黄昏光不再让皮肤维持中午的阴影结构。
- 背景路人可以移动，但不可与主体换脸、换衣或复制。
- 灰尘、水汽、布料飘动只在画面需要时加入，不靠杂物制造真实感。
