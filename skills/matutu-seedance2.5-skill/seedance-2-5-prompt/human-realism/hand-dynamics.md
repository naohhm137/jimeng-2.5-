# Hand Dynamics

手部问题的核心是“只有手势结果，没有手指/腕/握力的因果关系”。

## 动态要素

```text
finger independence
finger flexion
thumb opposition
wrist rotation
knuckle deformation
grip pressure
object contact
finger-object collision
```

## 拿产品

不要只写：

```text
holds the product
```

改为编译：

```text
fingers naturally wrap around the object,
thumb provides counter-pressure,
wrist remains anatomically aligned,
grip adjusts subtly as the object moves
```

中文示例：

```text
右手四指沿杯身左侧自然包合，拇指在右侧施加反向压力，
腕部保持中立位，杯身每移动一次，指节的屈曲压力做一次细微再平衡；
换手时先由另一只手从下方接住杯底，原手再松指。
```

## 手指独立

- 同一只手的五根手指可以同时屈曲，但不能像一块板一样整体折动。
- 无名指与小指通常随掌部联动，食指与拇指保留独立控制。
- 指尖接触物体时，指腹先发生轻微形变，再建立稳定接触。

## 避免手指畸形

```text
一只手五根手指只写整体弯曲
腕关节与物体边缘角度反生理
手指穿过杯壁/衣服
抓握时手不随物体受力变化
特写手部时手指结构模糊
```
